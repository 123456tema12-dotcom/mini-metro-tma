# Mini Metro — Telegram Mini App (TMA)

Полная веб-адаптация механик, стиля и атмосферы культовой игры **Mini Metro** (Dinosaur Polo Club), созданная с нуля для работы в виде **Telegram Mini App (TMA)** с оптимизацией под телефоны и планшеты.

---

## 🌟 Ключевые особенности и механики

1. **Оригинальная эстетика и визуальный стиль**:
   - Минималистичный дизайн схем метрополитена (в стиле Гарри Бека и Массимо Виньелли).
   - Точные палитры линий для мировых столиц (Лондон, Париж, Нью-Йорк, Токио, Санкт-Петербург).
   - Поддержка Retina / High-DPI экранов (чёткие векторные станции, линии и шрифты).
   - Переключение тем: **Дневной** (бежево-кремовый) и **Ночной** (тёмный графит).

2. **Динамическая генерация станций и пассажиров**:
   - Базовые формы станций: Круг, Треугольник, Квадрат.
   - Редкие уникальные формы: Звезда, Алмаз, Пятиугольник, Крест.
   - Пассажиры появляются со своими целевыми формами станций.
   - Круговой таймер переполнения (Overcrowding): при превышении лимита (6 человек на обычной станции или 18 на узловой) включается таймер обратного отсчёта. Если станция переполнена слишком долго — наступает Game Over.

3. **Многолинейный умный поиск путей (Pathfinding)**:
   - Пассажиры в реальном времени анализируют всю сеть линий метро (алгоритм BFS).
   - Поддерживаются прямые маршруты и пересадки на узловых станциях.
   - Поезда забирают только тех пассажиров, кому по пути данная линия или пересадочный узел.

4. **Еженедельные улучшения (Weekly Rewards)**:
   - Каждое воскресенье в 23:59 игра подводит итоги недели (количество перевезённых пассажиров).
   - Автоматическая награда: **+1 Локомотив**.
   - Выбор одной из двух бонусных наград:
     - 🚇 **Новая линия метро** (+1 цветная ветка);
     - 🚃 **Вагон** (+6 к вместимости поезда);
     - 🌉 **2 Моста / Тоннеля** (для пересечения рек и заливов);
     - 🏢 **Узловая станция (Interchange)** (увеличение вместимости станции до 18 пассажиров и ускоренная посадка).

5. **Процедурный аудио-синтезатор (Web Audio API)**:
   - Полная независимость от внешних mp3/wav файлов — звук генерируется браузером на лету.
   - Пентатонические гармонии: звоночки при появлении пассажиров, мягкие щелчки при посадке, триумфальные аккорды при доставке, тактовые ритмы часов и предупреждающие пульсации при переполнении.
   - Кнопка включения/выключения звука в верхнем меню.

6. **Адаптация под Telegram Mini App (TMA), телефоны и планшеты**:
   - Полная поддержка `Telegram.WebApp` API (`ready()`, `expand()`, `closingConfirmation`).
   - Поддержка Telegram Haptic Feedback (тактильная отдача при соединении станций, привязке и переполнении).
   - Жесты мультитач: Pinch-to-zoom (зум двумя пальцами), панорамирование карты одним пальцем по пустому месту.
   - Удобный drag-and-drop с увеличенными хитбоксами под пальцы:
     - Протянуть от станции к станции — новая линия;
     - Потянуть за круглый маркер на конце линии — продлить или закольцевать линию;
     - Потянуть за середину отрезка линии на станцию — вставить станцию в маршрут;
     - Быстрое удаление линии кнопкой `✕ Line` или кликом по маркеру цвета в инвентаре.
   - Адаптация под безопасные зоны телефонов (`env(safe-area-inset-top)`, `env(safe-area-inset-bottom)`).
   - Кнопка "Share Result on Telegram" для отправки рекорда друзьям или в канал.

## 🚀 Запуск игры

### Быстрый запуск локально

Поскольку проект написан на чистом современном HTML5 / ES Modules, для его работы достаточно любого статического веб-сервера.

В папке `c:\MiniMetro\metro-app`:

```bash
# Через Python (уже установлен в системе):
python -m http.server 8080
```

Затем откройте в браузере: `http://localhost:8080`

### Подключение к Telegram боту (Mini App)

1. Загрузите файлы из папки `c:\MiniMetro\metro-app` на любой бесплатный хостинг (GitHub Pages, Vercel, Cloudflare Pages, Netlify или свой сервер с HTTPS).
2. В Telegram напишите боту [@BotFather](https://t.me/BotFather).
3. Создайте бота или выберите существующего, выполните `/newapp`.
4. Укажите имя приложения, описание и вставьте HTTPS-ссылку на ваш хостинг.
5. Готово! Теперь игра запускается внутри Telegram на iOS, Android и десктопе по нажатию одной кнопки.

## 📂 Структура проекта

```
metro-app/
├── index.html        # Главная страница и разметка Telegram WebApp
├── css/
│   └── style.css     # Адаптивные стили, safe-areas, дизайн карточек
├── js/
│   ├── main.js       # Точка входа, жизненный цикл игры, управление UI
│   ├── engine.js     # Игровой цикл, симуляция времени, спавн, переполнение
│   ├── renderer.js   # Canvas 2D рендерер, рельсы, поезда, станции, зум/пан
│   ├── input.js      # Обработка тач-жестов, pinch-to-zoom, драг линий
│   ├── levels.js     # Города (Лондон, Париж, Нью-Йорк, Токио, СПб), реки, цвета
│   ├── pathfinding.js# Алгоритм графового поиска маршрутов пассажиров (BFS)
│   ├── audio.js      # Процедурный генератор звука на Web Audio API
│   ├── geometry.js   # Векторная геометрия, 45°/90° скругления, пересечения с реками
│   └── tg.js         # Интеграция с Telegram WebApp SDK и тактильной отдачей
└── README.md         # Документация проекта
```
